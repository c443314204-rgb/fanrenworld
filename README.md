## 零之二、v17.2：一地一遇 · 五十九处地志

### 一、每处地点都有一件自己的事

不是随机池里抽出来的通用事件，而是只长在那个地方的事：走了就没了，回来不会再有。

| 域 | 处数 | 例子 |
| --- | --- | --- |
| 天南 | 26 | 青牛镇挪了半步的石牛、嘉元城三层坊市的门、黄枫谷山门外坐了两年的年轻人、乱葬岗烧账页的人 |
| 乱星海 | 11 | 魁星岛码头的对峙、南鹤岛鹤来的七天、极阴岛城门那滴血、虚天殿退潮的路、外海那排城灯 |
| 大晋 | 8 | 晋京通铺里念错口诀的年轻人、小极宫梅林的琴、昆吾殿推开的石棺、天机阁递出的纸条 |
| 极西 | 7 | 千竹教界的竹子、风沙城换门、金刚寺九十二岁的拳头、残破古城桌上那碗热饭 |
| 慕兰 | 7 | 圣殿的黑石头、铁壁城的角声、部落篝火边忘词的老人、圣坛月圆之夜的萨满 |

每件都给了两条以上能走通的路：一条占便宜但担风险，一条吃亏但心里过得去。数字上都算得过来——
占便宜的多半是灵石、灵草、残片，或者一段修为；吃亏的多半是道心、名声、人情，偶尔是往后的一条线。

### 二、五十九处地志

每一处都补了三百字上下的白描：站在那儿能看见什么、什么人在这儿活着、有什么规矩、什么声音。
天南十六处原有、其余四十三处新写（`src/data_lore2.js`）。地志显示在地点面板下方，随地点切换。

### 三、事件的三个层次

| 类型 | 数量 | 触发方式 |
| --- | --- | --- |
| 一地一遇 | 59 | 只在那个地方，触发过就没了 |
| 随机事件 | 33 | 按域分池，走到哪都可能撞上 |
| 连续奇遇 | 13 步 / 4 条 | 上一次的选择把下一步留在某处 |

合计 92 条事件 + 13 步链。

### 四、招式收口：一本功法两式上下

以前《长春功》挂了十门法术，一学就有一整条技能栏。现在按品阶定上限：

| 品阶 | 招式上限 |
| --- | --- |
| 凡阶 | 2 |
| 灵阶 | 3 |
| 宝阶 | 4 |
| 半仙阶 | 5 |

《长春功》现在是 **火弹术 + 地刺术** 两式；其余 84 门功法一律 2–4 式，原先只有一式的补了一门同属性基础招（如《正阳劲》补"拳掌功"）。被摘下去的法术仍留在大表里，NPC、法宝、事件照旧能用。

在**有灵脉、又没人管**的地方（谷地/山林/沼泽/海岛/遗迹/山脉/村落/荒野/灵脉/废墟）可以「辟洞府」。

| 等级 | 造价 | 房间 | 每年维护 |
| --- | --- | --- | --- |
| 洞府 | 300 | 2 间 | 25 灵石 |
| 灵府 | 2600 | 4 间 | 120 灵石 |
| 洞天 | 16000 | 6 间 | 420 灵石 |

房间六种，都能升级（每级 ×2.1 造价）：

- **灵田**：种灵草，每年收一茬，年份越久越值钱。

## 零、v16.0：对话记忆 · 任务靠问 · 八棵人物树

### 一、他会记得你

每个 NPC 现在有自己的 `mem`。聊过什么、得罪过谁、拿过什么，都记着。

下次再开口，**开场就变了**：

| 人 | 你说过 | 再见时他先说的 |
| --- | --- | --- |
| 墨居仁 | 问过矿洞 | 「矿洞的事，问出什么了吗？」———他自己先提 |
| 墨居仁 | 追问到底 | 「上回你问了不该问的，我当你年轻。」 |
| 厉飞雨 | 一起喝过酒 | 「上回那口酒还行吧？」然后主动给你传消息 |
| 南宫婉 | 问过「活那么久也算活吗」 | 「你还记得那个问题。」然后告诉你血色禁地的真相 |
| 红拂 | 买过消息 | 「回头客。我这儿回头客不多。」 |
| 张铁 | 帮他说过话 | 「我进去了！」— 他已经进了七玄门，跟你说后山铁门里的事 |

说错话也会记着。问了不该问的，下次开场就是冷的；再问一次，他会动手。

### 二、主线要靠问出来

《青玉佩》第 3 步原来写的是「去黄枫谷」，现在改成 **`say`**：

拿着那半块玉**找对人开口**，任务才会往下走。

- **李化元**：取了玉给他看，他告诉你玄玉令的来历，还有八十年前那批人是怎么死的；问「为什么不能提黄枫谷」，他会说：那批人是黄枫谷派的。
- **陈巧倩**：她告诉你古修遗址底下的东西会**认玉**。要用血喂，喂够了门开，喂多了玉就认主。

问谁都能推进，但听到的东西不一样。

### 三、八棵人物树

原来六棵，这一版补上**张铁**和**董萱儿**：

- **张铁**：青牛镇的憨小子。你帮他说两句话，他就把你当朋友。进了外门之后，他会跟你说后山铁门里的车——车上盖着布，布底下露出一只很小的鞋。
- **董萱儿**：黄枫谷的幻术修士。她能听见你在想什么。夸她好看，她会笑；说她这张脸不是真的，整片林子会褪色，你会在原地站很久，掉一大截气血。

加起来：八个原著人物各有完整的树，六种性格各有通用树，一共十四棵。

## 零、v15.9：对话

NPC 以前只有一句随机台词。现在点「交谈」进的是**对话树**：一段话，两三个选择，选完接下一段。

### 六个人有完整的对话

| 人 | 聊什么 | 能聊出什么 |
| --- | --- | --- |
| 墨居仁 | 记名弟子、后山矿洞、那半块青玉佩 | 问得太深他会翻脸；筑基后再来，他会换个说法 |
| 厉飞雨 | 剑、赌、山外的世界 | 看破他起手太早，交情够了他会教你**眨眼剑法** |
| 南宫婉 | 掩月宗、长生、为什么活那么久 | 问"活那么久也算活吗"，她记你一辈子 |
| 红拂 | 消息买卖（两百灵石一问） | 坠魔谷底、血色禁地的真相，她说得比谁都直白 |
| 陈巧倩 | 剑、独处、为什么出剑 | 她把剑递给你握，说"过几年你要是还活着" |
| 李化元 | 宗门、贡献、结丹是什么感觉 | "心里多了一颗太阳，暖和，也烫" |

### 六种性格有通用对话

侠义、豪爽、谨慎、阴狠、痴道、市侩，各一棵树。走错一步会得罪人，走对了能白捡修为——

比如那个算经脉算了三十二年的痴道修士，如果你说中"拐的是灵气"，他会把三十年的笔记塞给你。

### 对话里能发生什么

改交情、涨名声/凶名、给灵石、给修为、给丹药、给功法、掉气血、引出后续。
有些选项带条件（交情够、灵石够、境界够）才会出现——**同一棵树，不同的人看到的选择不一样**。

## 零、v15.8：任务 · 地志 · 大量文本

### 一、任务

顶栏多了「任务」。一条主线 + 八条支线，全部条件驱动。

## 零、v15.7：大境界门槛 · 秘境征程 · 法术条件

### 一、大境界必须有天材地宝

以前破境只看一个百分比，点一下就过。现在每一层大境界都卡在一件东西上：

| 破境 | 需要 | 不带的后果 |
| --- | --- | --- |
| 筑基 | 筑基丹 | 只剩 5% |
| 金丹 | 结丹灵液 | 只剩 5% |
| 元婴 | 凝婴果 | 只剩 5% |
| 化神 | 化神花 | 只剩 5% |

这就是韩立为什么满世界找筑基丹——不是锦上添花，是**过不去**。

天之骄子（天灵根）带丹能到九成，四灵根不带丹只有 5%。灵根第一次真的决定命运。

### 二、秘境：一条从左走到右的关卡

点秘境不再是一锤子买卖，而是生成一条 7–8 层的路线：

| 地块 | 内容 |
| --- | --- |
| 妖气 | 打一场，赢了摸灵石 |
| 灵材 | 采灵草/矿石 + 灵石 |
| 异象 | 奇遇：口诀加修为 / 禁制反噬 / 捡到丹药 |
| 泉眼 | 回三成气血法力 |
| 岔口 | 选路：**左边**油水×1.6 但前头插一场战斗；**右边**稳妥、回一点血 |
| 守关 | BOSS，血量 1.5 倍 |

打赢守关，掉一件**天材地宝**（按你下一层境界算）+ 大量灵石与修为。打输了被轰出来，掉三成气血，东西拿不到。

途中的战斗会暂停回放，结束后按「继续前行」回到路线图，不会把你甩回地图。

### 三、法术条件（战斗终于有决策）

法术栏每一格下面多了一个下拉：

`无条件 / 敌血>60% / 敌血<35% / 我血<50% / 我有护盾时 / 我无增益时 / 法力>60% / 敌人两个以上`

自动战斗按顺序找第一个「冷却好了、法力够、条件也满足」的法术。也就是说，你写的是**一段策略**：

- 第 1 格：先手上增益（无条件）
- 第 2 格：敌血 > 60% 时用大招
- 第 3 格：敌血 < 35% 时用斩杀
- 第 4 格：我血 < 50% 时嗑药/开盾

战斗从「看动画」变成「验证我写的这套跑不跑得通」。

## 零、v15.6：闭关流程化 · 炼丹变控火

### 一、闭关：从「选几年」变成「一年一年熬」

以前是选 1/3/5/10 年，点一下，看结果。现在是坐在洞里，一年一年过，随时能收功。

**三种心法**

| 心法 | 修为 | 耗灵石 | 道心/年 | 出事概率 | 适合 |
| --- | --- | --- | --- | --- | --- |
| 稳健 | ×1.00 | ×1.00 | −2 | 低 | 家底薄、道心低 |
| 精进 | ×1.45 | ×1.15 | −4 | 高 | 灵石够、想快 |
| 参悟 | ×1.15 | ×1.35 | −1 | 中 | 长期蹲、求顿悟 |

**每年会撞上什么**

- 心魔翻涌：修为散 8%（道心越低越容易撞，精进再加一档）
- 顿悟：那一年 ×2.4，道心还回 6
- 灵气稀薄：那年只有六成效力
- 有人叫阵：凶名过 25 才有，不出洞就掉气血
- 洞府石缝长灵草：白捡一株
- 剩下的年份：只有水滴声，或者山风

面板上实时显示修为条、灵石、道心、寿元、灵气，下面是一条会累积的闭关纪事——你不是在看数字涨，是在看一段日子过去。

**为什么这么改**：修炼最该有感觉的是「熬」。灵石在烧、道心在掉、寿元在走，一年一年自己决定要不要再坐下去，这就是凡人修仙最真实的处境。

### 二、丹房：三转控火

以前炼丹是点一下、等七天。现在要自己控火：

1. 选丹方 → 扣材料 → 进丹炉
2. 一根指针从左扫到右，中间有一段绿区
3. 指针进绿区的一瞬点「凝」
4. 三转之后按凝住几次结算：

| 凝住 | 结果 |
| --- | --- |
| 3 次 | 上品，出 **两枚** |
| 2 次 | 中品，出一枚 |
| 1 次 | 下品，出一枚残丹 |
| 0 次 | 废丹，材料全废 |

三转的绿区越来越窄（26% → 20% → 15%），指针越来越快（1.75s → 1.45s → 1.2s）。手抖一炉材料就没了——这大概是全游戏最接近「底层修士」的时刻。

## 零、v15.4：面对面、境界压制、兵刃相交

### 1. 人物朝向

上一版的正道剑修是**背影**——镜像多少次都像背对，所以看起来没在面对面。已重画：正道剑修与老散修都改成「正面偏侧 45°、面朝画面右方、右手持械」，妖狼也翻成朝右。规则统一：**素材一律朝右，敌人用 CSS 镜像**，于是敌人永远面朝主角。

### 2. 境界压制

原来跨境界只有血量和法力在变，手感上就是「耐打一点」。现在加了三层：

| 机制 | 效果 |
| --- | --- |
| 攻击曲线 | 炼气 100 → 筑基 165 → 金丹 265 → 元婴 420 → 化神 640 |
| 境界压制 | 高一层 **伤害 ×1.30**，低一层 **×0.78** |
| 控制抗性 | 差一层，控制命中 **-14%**；反过来 +8% |

结果：金丹打炼气，一击是打同阶的 **4.5 倍**；炼气打金丹只剩 **0.23 倍**。一场越阶架大概两三下就分生死，而不是磨血。差两层以上时日志会写一句「境界压制」。

### 3. 兵刃相交

近身硬碰（`melee` 与普攻）现在走一套专门的打击时序，不再是「一个人挥、另一个人站着」：

| 时间 | 动作 |
| --- | --- |
| 0–190ms | 攻方起手把剑提到身后，守方压低身形 |
| 190–320ms | 双方同时上步，冲到刀剑相接的距离 |
| 320ms | **碰撞**：白闪 + 环形冲击波 + 交叉剑光 + 三十多道碎屑，全部集中在两把剑的交点 |
| 320–420ms | **抽帧顿挫**：整场停住 100ms，画面不动 |
| 460ms | **反震**：攻方退半步、守方连退，两人脚下同时扬尘 |
| 780ms | 稳住身形，抬剑重新对峙 |

兽类（用嘴咬）和鬼物（穿身而过）不走这套，仍用原来的动作。

## 零、v15.3：人物与术法换成生成图

上一版是手写的矢量剪影，形状能对上，但五官、衣褶、剑的质感出不来。这一版用图像模型重新出图，再抠成透明素材嵌进页面。

### 人物（6 张）

| 文件键 | 谁 | 造型 |
| --- | --- | --- |
| `player` | 韩立 | 深绿交领道袍，举剑斜指，45° 战斗站姿 |
| `human` | 正道剑修 | 束发戴冠，背剑，双手自然下垂 |
| `demon` | 魔修 | 双角、尖角肩甲、披散长发、魔刀、破损下摆 |
| `ghost` | 鬼物女修 | 长发遮面、无五官、破烂衣摆、悬浮 |
| `elder` | 老年散修 | 佝偻、长须、齐眉木杖 |
| `beast` | 妖狼 | 四足侧影，竖耳长尾，伏击姿态 |

出图方式是**纯白底 + 纯黑剪影**，脚本按亮度反算 alpha（`alpha = 255 - 亮度`），所以边缘自带抗锯齿、不会出现白边；再按每人指定一个墨色染色，最后转 WebP 内嵌。

### 术法（7 张）

`metal` 剑气 / `fire` 火 / `ice` 冰 / `thunder` 雷 / `ghost` 鬼雾 / `wood` 回春 / `shield` 护罩。

这七张是**纯黑底发光**，抠图同样用亮度当 alpha，画到 canvas 时用 `globalCompositeOperation = 'lighter'` 叠上去——黑底自然消失，只留光。原来那些圆形光点还在，负责火星、碎屑、雾气这些细节。

### 人物动作

贴图是整身刚体，动作靠偏移 + 旋转 + 透明度：

| 姿势 | 位移 | 旋转 | 用在哪 |
| --- | --- | --- | --- |
| idle | 0 | 0 | 站桩、呼吸起伏 |
| windup | -18px | -5° | 起手抬剑 |
| strike | +48px | 7° | 上步劈出 |
| guard | -8px | -3° | 格挡 |
| cast | -10/-12px | -4° | 施法 |
| hurt | -20px | -9° | 挨打后仰 |
| dead | +30px | 66° | 倒地淡出 |

出招节奏仍是 **预备 0.22s → 挥剑 0.16s → 停住 0.32s → 收势 0.42s**；挥剑期间按剑尖算 150ms 的淡白剑轨。

### 资源重建

```bash
python tools/build_sprites.py
```

脚本读 `dsh-image-gen/` 里生成的原始图，输出 `src/sprites.js`（含 base64 与锚点），`node src/build.js` 再把它内联进单文件 HTML。全套素材压缩后 755KB，成品页面 1.2MB。

### 锚点

头顶不能用「最上面一个像素」——举剑的人物最上面是剑尖。脚本按行统计宽度，第一个宽度超过最大值 14% 的行才算头顶；剑尖取上半身里最偏右上的点；脚底取最下面 2% 的重心。

## 零、v15.2：人物重做成「绑定剪影」

上一版的人物是一整块手绘路径，改不动、也站不住。这一版换成了**骨架绑定**：肩、肘、腕、胯、膝都是关节，动作只在关节上转，不缩放、不拉伸。

### 结构

- 静止姿势就是「正面偏侧 45° 战斗站姿」：右臂屈肘持剑抬在身前，左臂垂袖，重心微沉。
- 7 个关节：`J` 表里写着肩 / 肘 / 腕 / 胯 / 膝的静止坐标。
- 剑画在「腕点为原点」的局部坐标里，跟手一起转——**手和剑柄永远贴合**，不会飞出去。
- 肢体用 `bone(a, b, w1, w2)` 生成锥形，长度写死，所以画面里不会出现拉长缩短。

### 动作

姿势表 `POSE` 里七套：`idle / windup / strike / guard / cast / hurt / dead`，全部是「相对静止姿势的旋转量」。出招走 **预备 → 挥剑 → 停住 → 收势**：

| 阶段 | 时间 | 动作 |
| --- | --- | --- |
| 起手 | 0–220ms | 剑提到身后，重心后坐 |
| 挥剑 | 220–380ms | 上步、转腰、剑走斜线 |
| 停顿 | 380–640ms | 定住（这时剑光最亮） |
| 收势 | 640–1060ms | 回到站姿 |

挨打时 `hurt`（上身后仰、头偏），倒地 `dead`（塌肩、下沉），都是关节转出来的，不是整体歪一下。

### 剑轨

挥剑期间每帧记一次剑尖，画一道 140ms 的淡白弧；两点距离超过 64px 就直接断开重来，所以不会拉出横贯画面的长直线。

### 外观

| 来历 | 剪影 |
| --- | --- |
| 玩家 / 正道 | 交领道袍、发髻、垂袖、长剑；境界高则墨色更沉 |
| 魔修 | 头生双角、肩甲、魔刀 |
| 鬼物 | 破布下摆（锯齿）、半透 |
| 妖类 | 四足兽形（狼：竖耳、长尾、獠牙） |

剪影是**纯色平涂**，没有轮廓光描边；人物靠身后一团月雾从背景里剥出来。

### 背景

月夜远山：四层山脊（越远越淡）、山脚一层雾、地平一道月光、月盘三层光晕、松树与塔。天色仍按对手来历换（正道青灰 / 魔道暗红 / 鬼物幽紫 / 妖类苍黄）。

## 零、v15.1：斗法演出（重做战斗画面）

原来战斗只有「两张名牌 + 一条滚动日志」。这一版把画面做成了《夺宝中华》那类文字 MUD 的实景斗法：

### 舞台

- 一张水墨山景做底：三层山、月亮与月晕、雾带、松树与塔。
- **天色按对手来历换**：正道青灰月白 / 魔道血月 / 鬼物幽紫 / 妖类苍黄。
- 每场重新掷山形、月亮位置与松塔位置，所以同一场架不会看两次一样的景。

### 人物

站在台上的是**剪影立绘**，不是贴图：

| 来历 | 长相 |
| --- | --- |
| 我方 / 正道 | 道袍广袖、发髻横簪、飘带、背剑，剑尖指对方 |
| 魔修 | 头生双角、肩甲、血色横纹与魔刀 |
| 鬼物 | 破衣烂摆、无面、通体半透 |
| 妖类 | 换成四足兽形剪影（狼形，竖耳、长尾、獠牙） |

衣色按名字哈希在同类配色里挑，**境界越高衣色越沉、镶边越亮**；金丹以上加护体光晕与披风。

### 招式

每个法术都有自己的演出，**不是共用一个光球**：

- `battle_fx.js` 里有一张 `SPEC` 表，106 个法术逐条写了配方：
  - **形态**（17 种）：近身 / 剑气 / 投射 / 光束 / 天降 / 地涌 / 天罚 / 群体 / 环身 / 回复 / 护罩 / 禁锢 / 抽元 / 虚空 / 召鬼 / 掌印 / 爆发
  - **意象**（55 种）：剑、剑雨、巨剑、剑阵、雷、火、冰、藤、丝、链、印、眼、莲、鼎、魔、佛、骨、磁、镜、影……
  - 同一个法术每次长一样（按 id 哈希取种子），不同法术不会撞脸。
- 例：青元剑芒是三道金色剑气横扫；天罗真雷是紫电劈下 + 光柱 + 地波；
  大庚剑阵是十柄剑绕环结阵；擒仙大手是从天上按下来的一只大手；蜂云剑雨是九柄剑从天上落。
- 未收录的招式（NPC 随手一击、法宝技能）按**元素 + 效果 + 招式名**兜底推演，也有样子。

### 手感

- 挨打有飘字（暴击字号更大）、画面震动、地面起灰；倒下会侧倒、褪色。
- 胜负先在台上盖一枚**朱印「胜 / 败」**，约一秒后才落结算卡。

## 零、v5 改了什么

### 1. NPC 不再一年一层

每个人有**天赋**（0.25~0.92，3% 是天之骄子）。成长率 = 境界基础率 × 天赋系数：

| 境界 | 炼气 | 筑基 | 金丹 | 元婴 | 化神 |
| --- | --- | --- | --- | --- | --- |
| 基础率/年 | 9% | 4.5% | 1.8% | 0.7% | 0.3% |

- 四十年里，大部分人只挪一两层，只有极少数能连跳。
- **大境界的门槛**：成功率 = 8% + 天赋×28%（+5% 若有法宝）。
  失败的人里，**约 18% 身死道消**，其余重伤闭关（战力永久 -10%）。
- 所以你会看到日志里"某某破境失败，身死道消"。

### 2. 死了就退场，位置会补新人

死者当季从地点里移除，不再留一个灰掉的格子；空出来的位置由新生成的散修补上。
原著人物死了也一样，会在日志里报一句。

### 3. 结缘有用了

交情 ≥45 的人每年有 14% 概率上门，三种：

- **赠礼**：灵石 + 一枚丹药
- **指点**：修为 +（40 + 对方层数×30）
- **求救**：他被仇家追杀，帮你打一场（交情 +15），或者关门不认（交情 -20）

### 4. 突破更难，靠三样东西

玩家的大境界成功率改成：

```
0.18 + (灵根倍率-1)×0.28 + 战斗历练(0~0.30) + 功法被动 + 破境丹0.22
```

- 三灵根、没历练、没丹药：**18%**。
- 天灵根 + 打满历练 + 破境丹：约 **85%**（封顶）。
- 五灵根不加东西只有 **5%** —— 这就是为什么四五灵根得靠丹药。
- 新增功法被动 `breakBonus`：引气术 +3%、凝元功 +2%、大衍诀一至四层 +5%/+6%、大圆满 +8%、明王诀 +5%、三梵圣功 +4%。

## 零、v6：宗门

### 入门

黄枫谷（正道）和鬼灵门（魔道）各有一个山门。到地方点「宗门」：
- 正道宗门**不收修魔功的人**；魔道宗门**不收名声太干净的人**。
- 入门即外门弟子，年俸 20 灵石。

### 身份与贡献

外门弟子 → 内门（80 贡献）→ 真传（240）→ 执事（600）→ 长老（1200）。
每年发年俸、贡献 +3；真传以上额外 +4% 伤害，长老 +5% 气血。

### 差事（灵石与贡献的来源）

每门四件差事，随时可接：
- **交东西**：采药（3 灵草）、取血（2 妖皮）
- **打一场**：清剿妖兽、杀不长眼的散修
- **跑腿**：巡山、护送、护法

完成给贡献 + 灵石，耗时 3~12 天。差事办砸了（战斗失败）扣 10 贡献。

### 藏经阁

按身份开放：外门只有人阶/凡阶，内门开地阶，真传开天阶，长老才摸得到帝阶。
用**贡献**换，价格按品阶：人 30 / 凡 60 / 地 150 / 天 400 / 帝 900 / 仙 1500。

这是目前最稳的功法来源——比杀人安全，比奇遇可控。

### 派系

两堂二选一，站了队就改不了：

| 黄枫谷 | 剑堂 | 剑系伤害 +8% |
| --- | --- | --- |
| | 丹堂 | 丹药半价 · 疗伤 +10% |
| 鬼灵门 | 血堂 | 吸血 +6% |
| | 魂堂 | 神魂伤害 +10% |

每年有 22% 概率**派系倾轧**：赢的一方分贡献（+25），输的一方被扣（-20）。

### 叛出 / 逐出

叛出正道宗门：名声 -20、凶名 +15。
在正道宗门里修魔功，每年结算时会被执法队查出来，直接逐出。

## 零、v7：拍卖会 · 定时秘境 · 法宝两格

### 修了两个 bug

1. **「再入轮回」点完报 SecurityError / 乱码**：内嵌页面里 localStorage 被禁，而重开按钮直接调了它。现在重开只重置内存状态并回到标题页，不碰浏览器存储、也不整页刷新。
2. **人在鬼灵门，却能在黄枫谷打开宗门面板**：宗门面板现在认地点。回到自己山门才能接差事、进藏经阁、晋升；在别派山门点「宗门」，守门弟子会拦住你（"你是鬼灵门的人"）。

### 拍卖会（嘉元城）

每年换一批三件货：稀有功法（地阶/天阶）、法宝、丹药。起拍价按品阶，二楼有托在跟你抬价：
- 每次出价 = 当前价 ×1.15，三次机会；
- 出价超过对手的底价就落槌，否则对方跟价、价位上抬；
- 三次都没拿下，东西归别人。

这是目前灵石最大的去处，也是不打不杀拿高阶功法的唯一路子。

### 三个定时秘境

| 秘境 | 地点 | 周期 | 境界上限 | 产出 |
| --- | --- | --- | --- | --- |
| 血色试炼 | 血色禁地边缘 | 每 10 年 | 筑基圆满 | 灵石、残片、地阶功法 |
| 古修洞府开启 | 古修遗址 | 每 12 年 | 金丹后期 | 灵石、残片、天阶功法 |
| 坠魔谷血月 | 坠魔谷 | 每 20 年 | 元婴后期 | 大量灵石与残片、帝阶功法 |

- 每次开启可进 3 次，每次 25 天。
- 境界超了门径就塌（"秘境排斥你"）。
- 秘境一开，地点会凭空多出几个闻讯赶来的修士——他们是真的会跟你抢。
- 里面有 30% 概率直接打起来。

### 法宝两格 + 主动技

法宝从一件变两件：**主法宝 100% 属性、副法宝 60%**。每件法宝还带一个主动技，会进法术栏，按顺序自动放：

| 法宝 | 主动技 |
| --- | --- |
| 玄铁盾 | 玄铁壁：护盾 45 + 防御 +15% |
| 青竹蜂云剑 | 蜂云剑雨：45×2 随机剑伤，破防 15% |
| 白玉葫芦 | 玉露回春：回复 28% 气血 + 30 法力 |
| 虚天鼎 | 鼎镇山河：80 土伤 + 50% 定身 |

在储物袋或器坊里点「主 / 副」装备，法术栏会自动多出它的技能。

## 二、这一版新增

### 1. 修了南宫婉的功法 id bug

原先把法术 id（`shuangying`）写进了功法栏，显示成一串英文。已改成 `lingying`（灵影术），并给原著人物加了一层过滤：只认真正存在的功法。

### 2. 炼丹（灵草有用了）

在坊市点「炼丹」：

| 丹药 | 材料 | 效果 |
| --- | --- | --- |
| 疗伤丹 | 灵草 ×2 | 回 35% 气血 |
| 回气丹 | 灵草 ×2 + 矿石 ×1 | 回 45% 法力 |
| 培元丹 | 灵草 ×4 + 矿石 ×1 | 修为 +120 |
| 破境丹 | 灵草 ×6 + 矿石 ×2 + 古修残片 ×1 | 突破 +20% |

每炼一炉 7 天。材料靠采药、挖矿、奇遇、杀人。

### 3. 炼器 / 法宝（矿石与残片有用了）

在坊市点「炼器」，30 天出一件：

| 法宝 | 品阶 | 材料 | 效果 |
| --- | --- | --- | --- |
| 玄铁盾 | 人阶 | 矿石 ×4 + 40 灵石 | 减伤 8%，防御 +10% |
| 青竹蜂云剑 | 地阶 | 矿石 ×6 + 残片 ×1 + 120 灵石 | 剑系 +20%，暴击 +5% |
| 白玉葫芦 | 地阶 | 灵草 ×3 + 矿石 ×2 + 残片 ×1 + 100 灵石 | 每回合法力 +3，疗伤 +15% |
| 虚天鼎 | 天阶 | 矿石 ×8 + 残片 ×3 + 400 灵石 | 伤害 +8%，气血 +8%，减伤 5% |

- 只能同时**祭炼一件**，在「储物袋」或「人物」里换。
- 法宝加成直接进人物面板，战斗中生效。
- **NPC 也会带法宝**：金丹以上约 45% 有一件，战力 ×1.18，名字后面标「·持宝」；杀了有 60% 概率抢过来。极少数炼气修士也揣着法宝——那种人更不能惹。

### 4. 修炼不再免费

以前按「修炼」就能一路突破，现在：

- **每年要烧灵石**（炼气 12/年，之后每境 +18/年）。钱不够，连闭关都进不去。
- **闭关掉道心**（每年 -2.5）。道心低于 30 时，有 30% 概率走火入魔：掉 12% 修为、重伤、强制中断。
- 道心高于 80 时修炼收益 +10%。
- 斗法每赢一场，道心 +3、突破历练 +5%。

于是链条变成：**要修炼 → 要灵石 → 要采药/杀人/接活 → 杀人涨凶名、结仇家 → 仇家找上门**。钱和命是同一件事。

### 5. 远行以年计，但有传送阵

```
天数 = (距离/8)^2.4 × 修为速度^1.6 × 4
```

| 从青牛镇出发 | 近（七玄门后山） | 中（嘉元城） | 远（魔道据点） |
| --- | --- | --- | --- |
| 凡人 | 304 天 | 982 天 | 12 年 |
| 炼气 | 134 天 | 434 天 | 5 年 |
| 筑基 | 63 天 | 204 天 | 2.7 年 |
| 金丹 | 33 天 | 107 天 | 1.4 年 |
| 元婴 | 19 天 | 60 天 | 293 天 |
| 化神 | 11 天 | 35 天 | 171 天 |

凡人出一趟远门，回来人就老了。两个安全区之间可以走**传送阵**：3 天，80 + 距离×8 灵石。

## 三、之前几版的核心规则（仍然有效）

- **从凡人开始**：无修为无功法，先在青牛镇茶棚拿《长春功》引气入体。
- **主修 + 辅修**：主修被动全效、辅修减半；转修按品阶耗时（人 10 天 … 仙 720 天）。
- **灵根决定修炼效率**：天 2.0 / 双 1.45 / 三 1.0 / 四 0.55 / 五 0.35。
- **瓶颈**：修为满了闭关只剩 8% 收益，必须突破（战斗历练 +5%/场，破境丹 +20%）。
- **NPC**：凡人就写凡人；36% 的修士带一门功法，13% 的低阶修士身怀绝学但背后有人；每人有经历，逐年增长、进步、陨落。
- **态度**：修魔功惹正道，一身正气进魔道据点会被打；印象太差点开就可能挨揍。
- **切磋**不伤气血只耗法力；斗法/劫杀掉血，死了掉修为回安全区（硬核删档）。
